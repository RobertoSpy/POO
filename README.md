This repository contains the exercises and projects from my Object-Oriented Programming (OOP) course at university. The course introduced me to the foundational concepts of OOP and allowed me to apply them in a variety of exercises.

What I've Learned:
Fundamentals of OOP:
The course began with the basics of Object-Oriented Programming, including:

Classes and Objects

Methods and Constructors

Data encapsulation (using getters and setters)

The use of access modifiers for data protection

Core OOP Principles:
As the course progressed, I learned the core principles of OOP, which are essential to writing clean, modular, and maintainable code:

Encapsulation: Keeping data safe inside classes and only allowing controlled access.

Inheritance: Creating new classes from existing ones to promote code reuse.

Polymorphism: The ability for different classes to respond to the same method call in different ways.

Abstraction: Hiding implementation details and showing only essential features to the user.

Advanced Concepts:

Threads and Synchronization: Learning how to work with multi-threading to handle concurrent tasks.

Collections Framework: Working with various data structures such as ArrayList, HashMap, and HashSet.

File I/O: Using Input/Output streams to read and write files in Java.


Labs and Exercises:
The course was structured around practical labs that gradually introduced more complex concepts. From simple class creation to working with advanced features like threads, synchronization, and file I/O, each lab built on the previous one, providing a comprehensive understanding of OOP.
